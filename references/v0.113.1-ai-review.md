# v0.113.1 compatibility review

**Support:** [v0.113.1/d09d48e5 only](../README.md). Checkpoints remain tied to their creating build. The comparison below records the transition from v0.113.0.

## Vanilla changes

Compared v0.113.0/16ac0fe3 with `public-beta` v0.113.1/d09d48e5 on 2026-11-15, using ILSpyCmd 9.1.0.7988 for the new snapshot. Of 3,888 C# files, 20 changed; zero were added or removed.

| Change | Consequence |
|---|---|
| Stretch recognizes Adroit's Block and gates previews accordingly. | Preservation defaults cover the fix; enchantment identity/amount already distinguishes copies. Nimble/Fresnel Lens eligibility stays unchanged. |
| Show Off removes a zero-value upgrade marker. | Preview highlighting changes; saved Aim and card ranking stay unchanged. |
| Ordinary cloud writes exclude `.backup`/`.pre-repair`; directory synchronization also removes stale remote copies. History counts/lists only `.run` files. | Existing checkpoint delegation inherits the fix. [Save handling](../README.md#saves). Single-file `OverwriteCloudWithLocal` still bypasses suffix filtering. |
| Tooltips, arrow attachment, bestiary animations and card-library filters change. | Presentation only; arrow visuals use independently seeded `Rng.Chaotic`. |

Run RNG, rewards, pools, event eligibility, patch targets and run-save schemas remain unchanged. Policy conflicts: none. The [official notes](https://steamcommunity.com/app/2868840/allnews) additionally cover assets and translations, outside this code comparison.

## Compatibility changes

Initialization, deployment and test hosts require the exact v0.113.1 assembly hash. Manifests require minimum version 0.113.1. Test hosts refresh game files and verify their assembly before launch.

## Validation

Validated 2026-11-17 on v0.113.1: formatting/analyzers, 64 unit tests, 917 standalone checks and 971 RitsuLib checks per initialization order. The check and deployment scripts reject the v0.113.0 assembly. Earlier probes of `CloudSaveStore` backup/repair filtering and `RunHistorySaveManager` history filtering passed all 14 checks. Reproduce the current suite with the [validation command](../README.md#build-and-validate). Live Steam synchronization and visual gameplay remain unverified.
