# v0.113.1 compatibility review

**Support:** one package for both [verified builds](../README.md); gameplay policies and reward code are unchanged. Checkpoints remain tied to their creating build.

## Vanilla changes

Compared v0.113.0/16ac0fe3 with `public-beta` v0.113.1/d09d48e5 on 2026-11-15, using ILSpyCmd 9.1.0.7988 for the new snapshot. Of 3,888 C# files, 20 changed; zero were added or removed.

| Change | Consequence |
|---|---|
| Stretch recognizes Adroit's Block and gates previews accordingly. | Preservation defaults cover the fix; enchantment identity/amount already distinguishes copies. Nimble/Fresnel Lens eligibility stays unchanged. |
| Show Off removes a zero-value upgrade marker. | Preview highlighting changes; saved Aim and card ranking stay unchanged. |
| Ordinary cloud writes exclude `.backup`/`.pre-repair`; directory synchronization also removes stale remote copies. History counts/lists only `.run` files. | Existing checkpoint delegation inherits the fix. [Cloud contract](../docs/stage-1.md#cloud-and-verification-limits). Single-file `OverwriteCloudWithLocal` still bypasses suffix filtering. |
| Tooltips, arrow attachment, bestiary animations and card-library filters change. | Presentation only; arrow visuals use independently seeded `Rng.Chaotic`. |

Run RNG, rewards, pools, event eligibility, patch targets and run-save schemas remain unchanged. Policy conflicts: none. The [official notes](https://steamcommunity.com/app/2868840/allnews) additionally cover assets and translations, outside this code comparison.

## Compatibility changes

Exact assembly hashes select the active build for initialization and checkpoint metadata. Manifests retain minimum version 0.113.0. Test hosts refresh game files and verify their assembly before launch.

## Validation

Validated 2026-11-15: formatting/analyzers, 41 unit tests, and the same package on both builds: 205 standalone checks and 259 RitsuLib checks per initialization order. Another 14 probes of `CloudSaveStore` backup/repair filtering and `RunHistorySaveManager` history filtering passed on v0.113.1. Reproduce the current suite with the [validation command](../README.md#build-and-validate). Live Steam synchronization and visual gameplay remain unverified.
