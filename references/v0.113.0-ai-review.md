# v0.113.0 baseline review

Changes relevant to the mod, based on the [official changelog](https://store.steampowered.com/news/app/2868840/view/708914333639245837) and decompiled code.

## Randomness

| Change                                                                                                                                                                                         | Effect on the mod's rationale                                                                                                                   |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Shops use `Shops` for rarity, identity, upgrade checks and prices.                                                                                                                           | Shop generation leaves card-reward RNG unchanged; the card-rarity offset still depends on combat rewards.                                       |
| Event relic rarity uses event RNG.                                                                                                                                                             | The generic rarity sequence reconnects event and combat rewards.                                                                                |
| Brew and Delicate Frond use `NonCombatGeneration`; Alchemize retains `CombatPotionGeneration`.                                                                                             | The shared generating-effects supply reconnects sources vanilla now separates.                                                                  |
| Beat Down, Uproar, Stampede, Catastrophe and Hopper use `CombatCardSelection`; Entropy uses `CombatCardGeneration`.                                                                        | Auto-play selection stops advancing shuffle RNG. Hopper and potion card generation use separate streams; Entropy already shares generation RNG. |
| Permanent-upgrade relics, Beautiful Bracelet, Royal Stamp and Neow's Bones use `NonCombatGeneration`; Wing Charm uses `Rewards`.                                                           | Baseline ownership changes; the Royal Stamp → Whetstone steering example still applies.                                                        |
| Each [shuffle](../.cache/sts2-v0.113.0/decompiled/MegaCrit.Sts2.Core.Extensions/ListExtensions.cs) consumes one parent draw and shuffles through a child RNG, including empty/singleton inputs. | List size alone leaves later parent state unchanged; sorted-copy ties still affect results.                                                     |

## Content and state

- Six character pools and 61 ordinary events; ordinary-relic pool sizes and allocation counts remain unchanged.
- [Show Off](../.cache/sts2-v0.113.0/decompiled/MegaCrit.Sts2.Core.Models.Cards/ShowOff.cs) stores permanent Aim and updates its linked deck card. Its power retains the played copy until an enemy dies or the turn ends. The Shot carries per-copy Florescence damage.
- Bottled Song adds Wah → Cho → Ki cards through separate draws, allowing a multi-tag identity to repeat. The Magician channels random orbs; Museum adds a random curse; Waterfall directly adds an own-character Rare.
- Doors' Light option chooses its upgrade target; Axebot has fixed HP; Hopper excludes Quest cards. Dowsing suppresses combat on its fourth `?` visit.
- [Ki Chant](../.cache/sts2-v0.113.0/decompiled/MegaCrit.Sts2.Core.Models.Cards/KiChant.cs) restores preexisting draw cards above the newly shuffled cards. Coda and Cho Limbs derive turn-dependent costs from melody history.
- Ocarina generates from unlocked-character melody cards; Blot Out the Sky uses own-character Shoot cards. Their filters fit existing generation rules.
- [Memento Mori](../.cache/sts2-v0.113.0/decompiled/MegaCrit.Sts2.Core.Models.Cards/MementoMori.cs) chooses the lowest-HP enemy, breaking ties by enumeration order despite its `RandomEnemy` metadata.
