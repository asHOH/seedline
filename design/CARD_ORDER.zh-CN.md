# 卡牌处理顺序

[卡牌处理顺序策略](DESIGN.zh-CN.md#card-processing-order)的排序规则。

<a id="property-scope"></a>

## 属性范围

**持续属性**指卡牌当前的属性，计入在本场战斗中可跨回合边界保留至该实例下次打出的修正。包含书签和已升级开悟等卡牌专属效果，以及带刺手甲的能力牌费用 +1、腐化的技能牌免费等持续共享效果。排除可被其他卡牌消耗的共享次数，包括猛扑的下一张技能牌减费。爆发和回响形态不计入重放，三角铃鼓不计入保留。

**回合效果**在回合边界到期，例如未升级的开悟。阶段 4–5 明确将其计入。

其他比较使用持续属性。全部阶段都应用[范围排除](#scope-exclusions)。

<a id="identity-only-order"></a>

## 仅按品种排序

[变化批次](DESIGN.zh-CN.md#transformation-batches)评估阶段 1–3 时，使用各品种未升级、未附魔的基础属性，排除实例状态和战斗效果。不同品种若仍并列，使用阶段 3 的“品种”行确定先后。

<a id="comparison-order"></a>

## 比较顺序

从上到下依次比较阶段 1–6，首个差异决定排序。若仍并列，则遵循[卡牌处理顺序策略](DESIGN.zh-CN.md#card-processing-order)。

<a id="1-category"></a>

### 1. 类别

诅咒与任务 < 状态 < 打击 < 强悍武器 < 防御 < 强悍护盾 < 其他基础 < 其他攻击 < 其他技能 < 条件牌 < 能力。

打击/防御指初始牌品种。重放 >= 1 时，分别提升到其他攻击/技能。

将下列技能牌归为**其他攻击**：刀刃之舞、弹跳药瓶、漆黑、致命毒药、死神、末日降临、异鸟猛击、刀刃陷阱、无处可逃、湮灭、毒性爆发、蛇咬、暴风雨、炸弹、月亮、电击。

**条件牌**包括需要铺垫才能获得收益的牌、促成组合技的牌，以及选定的条件减费牌。成员固定如下，不随战斗状态变化。

| 池 | 条件牌品种 |
|---|---|
| 铁甲战士 | 全身撞击、狂宴、恶魔之焰、被遗忘的仪式、连环拳、契约终结、原始力量、狂怒、重振精神、添柴、踩踏、扯碎 |
| 静默猎手 | 预判、咕嘟冒泡、子弹时间、计算下注、腐蚀波、终结技、华丽收场、蜃景、谋杀、夜魇、精密瞄准、暗影步、融入暗影、狩猎 |
| 储君 | “抉择，抉择”、月面射击、独白、辐射、超质量体 |
| 亡灵契约师 | 幻景、亡魂牵引、牺牲、重构 |
| 故障机器人 | 弹幕齐射、散射炮、螺旋钻击、多重释放、四重释放、信号增强、同步、电流相生 |
| 愚者 | 弹跳、啾 四肢、终曲、怒放、生长、和声之盾、叽 诗句、钉住、寂灭、连根拔起、拧下 |
| 无色 | 天选、狠揍、金斧、贪婪之手、未掘宝石、急躁、心灵震慑、延伸、心神不宁 |
| 事件 | 交锋、双持、开悟、巩固、疯狂进食、堆栈 |
| 衍生 | 审判、恶魔 |

<a id="2-replay"></a>

### 2. 重放

重放 `r` 表示额外打出次数。诅咒、任务和状态牌先比较[品种排名](#identity-and-rarity-ranks)，再按重放次数升序比较。其他卡牌正常比较 `r`，提升类别的初始打击/防御比较 `(r - 1) / 2`。保留小数，`1, 2, 3` 对应 `0, 0.5, 1`。

<a id="3-within-category-order"></a>

### 3. 类别内顺序

诅咒、任务和状态牌使用[品种排名](#identity-and-rarity-ranks)，其余类别使用下表。

| 顺序 | 属性 | 升序规则 |
|---|---|---|
| 1 | 保留 | 无 < 有；包含符合范围要求的自带保留、附魔赋予的保留和额外添加的保留。 |
| 2 | 辉星费用 | `(无 = 0) < X < 1 < 2 < ...` |
| 3 | 稀有度档位 | 稀有度排名中，低于稀有 < 稀有或更高。 |
| 4 | 能量费用 | `0 < X < 1 < 2 < 蛇行 < 3 < ...`；蛇行使用此固定档位。 |
| 5 | 抽牌效果 | 无 < 有；即使抽牌数量为零，仍算有抽牌效果。编译冲击和生效中的迅速算有，已到期迅速不计抽牌。 |
| 6 | 稀有度 | [稀有度排名](#identity-and-rarity-ranks)。 |
| 7 | 卡池 | 角色牌池 < 无色牌池；事件与衍生牌池视为无色牌池。 |
| 8 | 品种 | 先按固定英文名称的字母顺序，再按卡牌 ID 排序。 |

<a id="4-copy-state"></a>

### 4. 副本状态

| 顺序 | 属性 | 升序规则 |
|---|---|---|
| 1 | 魂缚 | `魂缚 < 无`。 |
| 2 | 卡牌携带数值 | 携带的伤害、格挡或瞄准越高，排序越靠后；包括战斗内累计增长。附魔自身提供的加成按附魔相关行比较。 |
| 3 | 附魔排名 | [附魔排名](#enchantment-rank)。 |
| 4 | 附魔数值 | 低 < 高。 |
| 5 | 动量携带加成 | 低加成 < 高加成。 |
| 6 | 升级状态 | `未升级 < 暂时降级 < 已升级`；定义见下文。 |
| 7 | 愧疚战斗计数 | 愧疚已完成战斗次数少 < 多。忽略探寻的房间进度。 |
| 8 | 虚无 | `无 < 虚无`。 |
| 9 | 奇巧 | `无 < 奇巧`。 |
| 10 | 取回/待归还可用性 | 取回本回合首次打出的抽牌效果：已用 < 可用。流星锤/无休手斧在下次抽取手牌时的归还：无待归还 < 待归还。 |
| 11 | 抑制恢复等级 | 低 < 高；无 = 0。 |
| 12a | 是否有回合效果 | `无 < 有回合效果`。 |
| 12b | 计入回合效果的辉星费用 | 两者都有回合效果时，比较最终辉星费用：`(无 = 0) < X < 1 < 2 < ...`。 |
| 12c | 计入回合效果的能量费用 | 两者都有回合效果时，比较最终能量费用：`0 < X < 1 < 2 < 3 < ...`，包含蛇行的实际费用。 |
| 13 | 临时关键词 | `无 < 临时保留 < 临时奇巧 < 两者都有`。 |
| 14 | 蛇行卡牌的持续能量费用 | 低 < 高。 |

携带数值包括遗传算法的格挡、炫技的瞄准，以及巨镰、君王之剑、全力射击、暴走、爪击、撕咬、王者之拳和痛殴累计的伤害。

**升级状态**。未升级指当前未升级，且没有待恢复的升级；暂时降级指当前已降级，且有升级等待恢复。已升级档位内按当前确切升级等级确定先后。

第 12b–12c 行将回合限时修正计入后重新计算费用，保留修正应用顺序。第 13 行涵盖独门技术的临时保留和手上技法的临时奇巧。

第 14 行使用蛇行在[持续属性](#property-scope)下的最终能量费用，包括首次掷值前和后续覆盖后的费用。

<a id="5-tie-breaks"></a>

### 5. 并列处理

将[附魔排名](#enchantment-rank)中用 `=` 连接的一组，按书写顺序视为 `<` 来确定先后。其中的已到期附魔，按各自原本生效时在附魔排名中的顺序比较。

若仍并列，按修正的应用顺序，先比较已存的辉星费用修正列表，再比较能量费用修正列表。保留存储中的重复项与被覆盖条目。

记录按字典序比较。辉星费用使用 `(expiration, value)`（到期条件、数值），能量费用使用 `(expiration, operation, value, reduce-only)`（到期条件、操作、数值、是否仅降低）。若列表前缀相同，较短者在前。

使用 `turn-or-play < turn-only < until-played < combat-long`、`set < add`、数值升序及 `false < true`。

**取舍**。即使未来费用行为相同，排序与[战斗路由等价](DESIGN.zh-CN.md#combat-card-routing)仍可能依赖修正历史，例如到期条件相同的两个 `−1` 修正与一个 `−2` 修正。

## 附魔排名

华彩 <（无 = 已到期附魔 = 涡旋 = 克隆 = 注能）< 动量（携带加成 = 0）< 灵魂之力 < 锋利 < 特兹卡塔拉的余烬 < 活力 < 动量（携带加成 > 0）< 腐化 < 本能 < 墨影 < 灵巧 < 黏糊 < 伶俐 < 播种 < 蛇行 < 完美契合 < 稳定 < 王室认证 < 迅速。

| 效果 | 来源与范围 |
|---|---|
| 烟雾 | 烟雾弥漫。 |
| 昏眩 | 昏眩。 |
| 流电 | 电球头的流电；能力牌。 |
| 污染 | 感染棱柱的活力火花；技能牌。 |
| 恶咒产生的虚无 | 幽灵骑士的恶咒。 |

**排除的卡牌**包括知识恶魔仅用于菜单的状态牌和仅限多人的卡牌。
