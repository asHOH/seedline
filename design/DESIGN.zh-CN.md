## 目标与原则

**目标**是在相同种子的不同路线与决策下，提供相近的奖励、选择和战斗挑战。对齐相互对应的机会，例如每局的第一家商店或第三次普通战斗奖励。

**公平原则**是保留有意义的后果，同时尽量减少对无关后续玩法的影响。

**行为保留**是保留原版玩法，仅为有意的对齐取舍或修正非预期行为而改变。

**歪种**指不受控的随机性导致同种子对局的结果分歧，往往出现在前中期。仅因有意共享的序列被消耗次数不同而产生的差异属于良性差异，包括后期分歧。

**批次顺序中立**要求同一批次改变点击或枚举顺序时，受影响的品种或状态以及后续随机状态保持不变，除非效果明确依赖顺序。同时保留展示顺序和玩法效果。

### 相对原版的偏差

分别评估 **NoSL**（不存读档）和 **SL**（通过存读档探索）的原版偏差。[评级与记法](#偏差评级)说明展示、可察觉性和策略影响，[共享偏差](#共享原版偏差)说明多个策略引用的影响。

## 范围

面向 StS2 v0.114.0（`public-beta`）的独立模组，用于日常游玩，也适合竞赛。

适用于种子、版本和规则一致，内容全部解锁且未被其他模组修改的标准和恐惧单人对局。

使用本模组开始的新对局开放全部内容，但不改变档案解锁状态和进阶上限。

**排除**教程覆盖逻辑（包括预设奖励和 Boss 解锁顺序）、不支持的[自定义对局调整项](#自定义对局调整项)、重复访问同一事件，以及游戏更新中移除的内容。

**数值范围**不包含仅由舍入或精确采样边界造成的微小概率差异。

**默认难度**为稀缺（进阶 7 及以上）；低于 A7 时使用 A0–6 概率。

**讨论边界**为基础随机结果和影响随机操作的调整效果交互。保留调整效果，包括各类蛋、菲涅耳透镜和固定折扣。

## 概念与术语

随机操作分为以下类别。

- **奖励**包括生成的奖励品种与数量，以及永久变化结果。
- **遭遇**包括受影响卡牌或物品的选择、房间内容、具名事件选项和战斗随机性，分为**非战斗**和**战斗**。

[遗物交换商](#遗物交换商)将交出遗物的选择和替换遗物都归入遭遇。

策略分类与 RNG 归属相互独立，奖励也可以使用事件 RNG。

### 游戏语境

- **品种（identity）**指具体是哪种卡牌、物品、敌人或事件。例如，痛击与痛击+ 属于同一品种。
- **ID**是标识标签。
- **地图类型**指地图标记；`Unknown`（`?`）可能解析为不同房间类型。
- **房间类型**指解析后的房间类别。本设计将先古之民单独计类。事件可以在不改变地图类型的情况下开始战斗。
- **战斗**指任何战斗，包括事件战斗。**普通战斗**指不属于精英或 Boss 类别的战斗。

### 物品与奖励

- **生成/获取**中，生成决定物品是什么，获取指实际获得它。
- **卡牌奖励选项组**指同时提供以供选择的卡牌，包括补充卡牌和备选卡包。**卡位**是选项组中的一个位置。
- **跳过奖励**指获取机会结束时仍未领取奖励。
- **直接添加卡牌**指既不能选择品种，也不能在看到结果后跳过的卡牌添加。
- **常规遗物**包括普通、罕见、稀有和商店稀有度。

### 随机性与寻址

- **RNG**是随机数生成器。
- **[随机状态](#rng-派生与寻址)**是跨操作追踪随机过程的内部信息。
- **用途**指随机性决定什么，例如选择、排序或升级。
- **掷值**指采样随机数的操作或所得数值。
- **重置取新值**指为时钟或稀有阈值换上一个新值。
- **池/序列**中，池定义候选品种，序列是随机数或物品品种等条目的有序集合。重复的值或品种也属于不同条目。
- **过滤条件**决定哪些候选项或条目符合条件。
- **抽取**指从池或序列中取出物品或条目。
- **选择**指游戏或玩家选中某个候选项。
- **分区**指按来源、池或用途等类别分离随机状态或有限库存。随机状态分区所用的池可以重叠。
- **隔离**指将战斗、药水使用等不同机会的随机性分开。某个机会内的消耗不改变另一个机会分配到的掷值或序列。
- **配额**指分配给某来源、并排列成序列的有限遗物库存。
- **三元组序列**指每次消耗连续三个完整条目（**三元组**）的卡牌品种序列。
- **序号**指机会在所属类别中的位置。除非限定范围，否则计数贯穿整局；限定范围的计数在每个范围实例内重置。
- **逻辑实例/实体副本**中，逻辑实例是一份副本的持久记录，实体副本是当前关联该记录的卡牌。
- **[实例地址](#卡牌标识)**是逻辑实例的来源 ID，每份副本各不相同。
- **[卡牌键](#卡牌标识)**是用于选择和基于来源洗牌的持久卡牌 ID。
- **选择键**是候选项在某种选择用途下的 ID。
- **[选择状态](#寻址与状态)**是逻辑实例携带、决定其未来选择的隐藏信息。
- **路由**指在品种和玩法相关状态相同的合格卡牌中选择逻辑实例，再将其关联到玩家选中的实体副本。

## 全局规则

### 默认保留行为

除非策略明确改变，否则保留现有行为，包括以下内容。

- 来源的可用性、池、资格条件、选择、费用与奖励。
- 选项组大小、选取数量、批次边界、重复规则、生成属性和升级规则。
- 触发条件、效果时机与顺序、调整效果和展示。

### RNG 派生与寻址

随机状态包括 RNG 状态、序列内容与位置、机会计数器、已存储掷值和选择优先级。

**不变量——独立派生**。新增或重新寻址的随机性，由对局种子 + 用途与共享范围 ID + 策略指定的地址分量派生。同一完整地址复现相同掷值或序列；独立用途采用独立派生和状态。仅在策略规定共享或耦合时共享随机性。明确保留的基线 RNG 沿用其既定寻址。

新增或重新寻址的随机性，其局部地址与候选地址隐含对局种子。设计中的地址表达式用 `+` 表示分量的无歧义组合，而非算术加法。共享范围可隐含，也可由共享组、池等策略地址分量表达。使用稳定 ID 而非显示名称，并区分序列地址与当前位置。

RNG 地址中的范围内序号表示 `(scope ID, count)`；幕内序号包含幕数，事件内序号包含事件 ID。

**卡牌选择键**。获取后的选择与路由使用[卡牌键](#卡牌键)，并遵守[战斗卡牌选择状态](#战斗卡牌选择状态)，绝不使用当前列表位置。

**选择平局处理**。极少见的随机选择优先级相等时，按生成它们所用选择键的升序打破平局。

### 共享结果供给

**不变量**。若下一次抽取不能满足请求，且同一共享范围内预计还会有类似请求，优先从该供给解决，接受后续抽取发生位移。不要仅为当前机会生成一个其他对局可能永远见不到的结果。

### 条目地址

条目地址由原始来源序列 + 原始条目位置组成，用以区分重复品种的不同实例。

**不变量——稳定地址**。条目经过移动、过滤推进、[借用](#借用)、移除和归还时，保留原地址。

**不变量——仅展示重排**。只改变显示位置，条目的地址、附着随机状态和组归属都随条目保留。

### 机会消耗时机

**不变量——消耗时机**。对于消耗机会的操作，仅在结果已可揭示或领取时生成结果并推进随机状态，即使结果最终未揭示、被拒绝或跳过。

延迟奖励在变得可获取时消耗机会，而不是在获得创建它的效果时消耗。

**例外**是[药水效果机会](#药水效果机会)，丢弃、交易和覆盖范围内的跳过奖励也会推进。

### 存档状态

保留[原版对局存档检查点](#对局存档检查点)。每个检查点保存复现后续结果所需的全部模组状态，并在房间重新生成前恢复。

## 可复用机制

### 过滤抽取

**核心思路**是取出下一个合格物品，同时不把跳过的物品拉到后续抽取的前方。

**推进**。返回首个合格条目，再将每个后续合格条目移到前一个合格位置。不合格位置不变。例如合格条目 `A`、`B`、`C`……位于 2、6、8……，则返回 `A`，将 `B` 移到 2、`C` 移到 6，依此类推。

**延迟推进法**。无限序列和有限遗物配额都按需执行推进。

标记记录待执行推进，并冻结原抽取时的资格条件，包括批次排除与依赖状态的限制；当前抽取仍执行当前资格条件。

- **过滤抽取**返回首个合格条目，并用该过滤条件的标记替代它。
- **标记解析**将其后下一个合格条目移入标记位置，并在供给位置留下同一过滤条件的标记。仅当前向抽取或递归标记解析遇到标记时才解析。
- **无过滤抽取**先解析队首标记，再返回条目并删除抽取位置。

**标记碰撞**。使用过滤条件 `Y` 的抽取遇到 `X` 标记时，先解析该标记。

- 解析所得条目不符合 `Y` 时，留在标记原位置，继续寻找符合 `Y` 的条目。
- 符合 `Y` 时，返回条目，并在该位置放置 `Y` 标记。`X` 标记留在供给位置，表示先推进 `X`、再推进 `Y`。

后续碰撞递归应用此规则，包括相同过滤条件的碰撞；两次推进需要两个标记。

若[借用](#借用)后配额中仍无合格条目可解析标记，则使标记失效，再继续抽取。

### 遗物尾部抽取

倒序扫描存储位置，跳过全部标记和不合格条目，移除首个合格遗物。

### 固定选择优先级

**范围**为每局、每个共享范围内的一次选择或批次。

仅在选择机会到来时，以用途 + 共享范围 + 选择键计算每个候选项独立均匀的优先级 `U_i ∈ (0, 1)`，选取合格项中的最低优先级。

**加权单选**。候选项权重为 `w_i` 时，选择 `-ln(U_i) / w_i` 最小者，概率为 `w_i / Σw`。固定相对权重使候选项移除后剩余项的排名不变。

### 配对优先级分配

将候选项分配到不同位置。

以用途 + 共享范围 + 候选 ID + 位置 ID 派生独立均匀优先级。反复分配可用配对中优先级最低的一对，再移除该候选项和位置。平局先按候选 ID、再按位置 ID 打破。

### 持久时钟

**核心思路**是跨机会均匀选择实例时，保留指数时钟，并在每次随机选择后修正仍合格的未选项。[持久选择](#持久选择)、[战斗选择](#随机战斗卡牌选择)和[战斗卡牌路由](#战斗卡牌路由)策略规定共享方式及局部时钟规则。

**地址与状态**。每个逻辑实例初始时钟为 `e_i = -ln(U_i)`，其中独立的 `U_i ∈ (0, 1)` 由用途 + 共享范围 + 选择键派生。

若重置取新值使用实例级计数，则每次独立掷值由用途 + 共享范围 + 选择键 + 重置次数派生。

**选择与更新**

1. 选择合格实例中时钟最小者，其值为 `m`。
2. 提交时消耗其时钟，并从每个未选中但合格的剩余实例时钟中减去 `m`。不合格实例保留时钟，不相减也不重置。

策略规定何时、如何从同一分布为已消耗时钟取新值。

**批次**。从固定合格集无序均匀抽取 `k` 个不同实例时，选择抽取前最小的 `k` 个时钟，并从每个未选中的合格剩余实例时钟中一次性减去第 `k` 小时钟。每个选中时钟只消耗一次。基于同一资格快照提交，不依赖 UI 点击或枚举顺序。有意按顺序改变资格的效果仍保留该区别。

玩家操作不会仅因改变成员而推进玩法选择器的时钟；路由有自己的范围。固定目标和明确影响全部对象的效果也不消耗选择时钟。

**理由与限制**。指数分布的无记忆性保留均匀选择概率，同时保留共同参与的剩余实例间的相对顺序，但不能跨不同资格历史保留一个全局排名。例如 `A`、`B`、`C` 的时钟为 `0.5`、`0.6`、`0.7`；若只有 `A` 与 `C` 参与且选中 `A`，剩余 `C` 的排名就会超过未参与的 `B`。

### 路由

**范围**为玩家选中卡牌的[战斗外](#战斗外卡牌路由)和[战斗内](#战斗卡牌路由)操作。对应策略定义等价关系与操作共享方式。

用[持久时钟](#持久时钟)选择逻辑实例，再将其关联到被点击的等价副本，使隐藏状态的选择不依赖点击了哪份副本。已由随机过程选定的逻辑目标绕过路由。

**路由边界**。保留显示顺序，在被点击副本的牌堆位置应用效果，并遵守来源的移动与排序规则。例如全息影像移除被点击的弃牌条目，而之后万物一心按弃牌堆顺序读取剩余条目。

**批次关联**。与资格快照一起记录展示顺序。只有包含被点击副本的等价类参与重新关联和路由时钟更新。

1. 每个参与类中，将选中的逻辑实例按选择前路由时钟升序，与按展示顺序排列的被点击副本配对。
2. 将该类剩余逻辑实例按地址顺序，分配给按展示顺序排列的未点击副本。
3. 完成选择后再应用效果。

关联置换与时钟更新随操作一起提交。若选中的逻辑实例仍存续，则按该实例的重置次数为路由时钟取一次新值。玩家选择单例或整个等价类时也遵守此规则。

**耦合上限**。从含两个和三个选择键的嵌套集合中单选时，共享独立优先级以 `2/3` 概率选中同一键，达到均匀选择的最大值。不同选择键或资格历史可能降低一致率。

### 机会专属选择优先级

每次机会重新应用[固定优先级采样](#固定选择优先级)。以用途 + 机会地址 + 选择键派生优先级，不包含候选集合或列表位置。

#### 药水效果机会

**范围**为[药水生成卡牌](#药水生成卡牌)与[异蛇之油费用](#随机能量费用)。

每种药水拥有独立的整局效果序号。

| 操作                   | 序号推进                 |
| ---------------------- | ------------------------ |
| 已提交使用，即使未掷值 | 推进一次。               |
| 丢弃或交易             | 推进一次。               |
| 在奖励界面跳过药水奖励 | 每份跳过的奖励推进一次。 |
| 获取                   | 不推进。                 |

**大锅例外**。大锅提供的每瓶药水，为该类型授予一次豁免；任何原本会推进该类型效果序号的操作，改为消耗一次可用豁免。未用豁免在进入下一房间时失效。

**原版偏差——SL 4(↑)**。丢弃、交易或跳过药水可以重掷下一瓶同类型药水的结果。因此，想为后续战斗保留有利随机结果，需要拿起并保留其他同类型药水。

### 稀有度与品种序列

**核心思路**是跨路线对齐同类物品的连续机会，并为稀有度与品种使用独立的共享范围和序列状态。

**范围**包括遗物、药水、卡牌、永久变化与覆盖的直接添加。

来源掷稀有度时，消耗其**稀有度掷值序列**的一个值；固定稀有度请求仅消耗品种。若存在按稀有度划分的**品种序列**，对其使用[过滤抽取](#过滤抽取)；否则在池序列上按请求的稀有度过滤（若有）。来源策略规定共享方式和 RNG 例外，[生成共享关系](#生成共享关系)提供汇总。

**生成与生命周期**。药水/卡牌的品种与稀有度掷值序列按需无限生成，使用按指定来源和池分区的独立 RNG。除非来源另有规定（如加权或分组生成），每个新生成的药水/卡牌品种条目都从所属池中独立、均匀、有放回抽取。仅有限遗物配额进行[借用](#借用)。

品种序列使用[过滤抽取](#过滤抽取)，包括商店批次去重过滤，不额外掷稀有度；[遗物尾部抽取](#遗物尾部抽取)和[旺购百货的品种移除](#旺购百货)除外。跳过的条目仍可用于合格抽取和借用。

三元组序列在生成时保留各卡位稀有度，同时拒绝该三元组内重复的品种候选。其他卡牌序列通过过滤抽取执行来源要求的重复排除。

### 卡牌选择与处理

#### 卡牌等价

等价要求品种与玩法相关状态相同。隐藏选择状态和牌堆位置不拆分类别。

**不变量——等价副本**。除依赖位置的效果外，选择不同等价副本应保留品种/状态层面的结果。[路由](#路由)为覆盖的玩家选择落实此规则。

#### 战斗外卡牌路由

**战斗外等价**比较卡牌品种、升级等级、附魔品种与数量，以及适用的持久进度，包括遗传算法的 `IncreasedBlock`、巨镰的 `IncreasedDamage`、炫技的 `IncreasedAim`、探寻的 `RoomsEntered` 和愧疚的 `CombatsSeen`。在支持范围内，忽略冗余当前值字段、变化历史、获取元数据、藏宝图的附加字段及疯狂科学的类型/附加效果配置。基线见[持久卡牌状态](#卡牌状态与选择)。

下列战斗外操作中，各来源按操作和卡牌品种共享[路由时钟](#路由)。

| 路由范围 | 操作                                           |
| -------- | ---------------------------------------------- |
| 升级     | 对玩家选中卡牌的升级，包括佩尔之牙的初始选择。 |
| 附魔     | 对玩家选中卡牌的附魔，跨附魔类型与数量共享。   |
| 永久移除 | 移除、变化和熔合者的合并。                     |

共享移除范围，使[输入注销](#战斗外卡牌生命周期)后的剩余原卡保持对齐。

#### 战斗卡牌路由

每次玩家选择已有战斗卡牌时使用[路由](#路由)。只有该次选择可用的副本参与，并遵守[战斗卡牌选择状态](#战斗卡牌选择状态)。

按卡牌品种划分路由时钟。打出、丢弃、消耗、取回手牌、升级、附魔和变化各自跨给予来源共享一个路由范围。其他选择以选择用途和给予来源为范围，包括深谋远虑放回抽牌堆顶的操作。

等价判断使用[卡牌处理顺序](#卡牌处理顺序)中的状态比较，但排除来源排名，并包含对特定副本有实际影响的待结算效果。

**永久牌组对应关系**。遗传算法、巨镰、炫技和黏糊副本按其精确关联的永久牌组实例分组，纯战斗副本另成一组。偷窃草蜢的偷窃待结算时，将此分组应用于所有卡牌品种。

每个等价类内，整体路由逻辑实例，包括选择状态、洗牌分配、[异蛇之油入手分配](#随机能量费用)、复制关系，以及上述受保护情况之外的牌组关联。活动引用随逻辑目标保留。

**[重掷减少](#房间内重掷减少)**。点击等价副本会为后续战斗选择、洗牌和异蛇之油费用选中相同隐藏状态。

#### 卡牌处理顺序

对无序卡牌批次的随机操作处理，采用[品种与玩法相关状态排名](CARD_ORDER.zh-CN.md)。来源策略指定适用的比较项。

并列的已有实例按[实例地址](#卡牌实例地址)升序排列，状态始终随实例保留。

保留显示顺序和有意的顺序效果；奖励选项组在仅展示交换之前使用条目顺序。

#### 变化批次

一次变化批次包含一同选中的原卡。

按[仅品种顺序](CARD_ORDER.zh-CN.md#仅按品种排序)为选中原卡生成替代卡。每个输入品种内，按生成顺序将替代卡与按变化前展示顺序排列的原卡配对。

### 共享原版偏差

#### 后续操控减少

**原版偏差——SL 4↓(↓)**。通过提前消耗随机数来操控后续结果的规划决策减少。例如，[战斗内随机充能球](#随机充能球类型)使玩家无法为下一场战斗安排有利的充能球序列。

凡符合该定义之处，隐含适用此偏差。

#### 房间内重掷减少

**原版偏差——SL 3A(↓)，除非局部评为 SL 4(↓)**。以下部分操作不再改变房间随机结果。

- 其他随机效果、强制选择或失败操作。
- 操作/枚举顺序或等价副本选择。

#### 合格集变化时的备选结果改变

**原版偏差——SL 3A**。即使保留每次选择的概率，SL 探索不同合格集时可获得的结果仍可能变化。备选结果可能改善，也可能消失。

## 来源策略——奖励

### 遗物

#### 配额分配

一次性构建互不重叠的通用奖励、商店和送货员配额，目标分别占每个普通/罕见/稀有池的 **45% / 35% / 20%**。包含不能在商店出现的遗物。全部解锁时采用以下数量。

| 稀有度 | 通用奖励 | 商店 | 送货员 |
| ------ | -------- | ---- | ------ |
| 普通   | 12       | 9    | 5      |
| 罕见   | 14       | 11   | 7      |
| 稀有   | 17       | 13   | 8      |

每个来源有一条按需无限生成的稀有度掷值序列，以及按稀有度分别打乱、独立推进的品种序列。商店另有一条包含全部商店稀有度品种的打乱序列。

没有[借用](#借用)时，通用奖励机会最终必须展示每个仍合格的条目；其他来源的多选一选项组必须保留未选中的通用条目。

#### 来源分类

默认将隐藏随机遗物奖励归入通用奖励来源，包括付费奖励和遗物触发的给予。延迟奖励与给予它的遗物分别分类。

**原版偏差——SL 4↑**。事件中的通用遗物给予可揭示下一份遗物奖励的确切结果；原版只能揭示某一稀有度的下一个品种。

#### 借用

**对齐边界**。来源分区的保证不涵盖借用的影响，最终兜底不要求对齐。

请求稀有度没有合格的本地条目时，通过[尾部抽取](#遗物尾部抽取)从其他来源同稀有度配额借用。送货员先借通用奖励、再借商店；通用奖励和商店先借送货员、再借另一来源。

[标记解析](#过滤抽取)期间也执行借用，但不在供给方配额中放置过滤抽取标记。

**最终兜底**。从请求稀有度开始，按商店 → 普通 → 罕见 → 稀有的顺序，逐个尝试本地条目与同稀有度借用。全部失败则返回头环，不再掷稀有度。

基线见[遗物袋](#遗物袋)。

### 宝箱

#### 奖励生成

进入非空宝箱房时，宝箱序号推进一次，同时生成金币与遗物奖励。

- **金币**由宝箱序号生成基础金币，与战斗金币独立。
- **遗物**消耗一个通用稀有度掷值条目，派生[标记寿命掷值](#有限寿命宝箱标记)，并从之后的宝箱中排除抽到的品种。

白银熔炉的空宝箱房不生成任何奖励，也不推进宝箱序号。

#### 遗物推进

**意图**是将获取遗物导致的角色专属遗物概率提升分散到后续位置。

从所掷稀有度的通用品种序列抽取下一个合格的非角色专属遗物，以[有限寿命标记](#有限寿命宝箱标记)替代抽出的序列条目。

- **获取**时注销遗物；标记到期消失，剩余条目收拢。
- **跳过遗物**时，将抽到的条目作为标记的**携带条目**保存；到期时它替代标记成为遗物条目。

必须在到期前结算选择，包括 `x = 0`。永久不合格或在别处获取会清除携带条目，但保留标记寿命。

头环奖励绕过标记；跳过不改变库存，获取保留[基线品种移除](#遗物袋)。

##### 有限寿命宝箱标记

采用[过滤抽取的推进与碰撞规则](#过滤抽取)。宝箱标记在推进 `x` 个合格条目后到期，或在解析时借用后仍耗尽合格供给时到期。每次转移令 `x` 减一，并将标记移至供给位置。碰撞保留每个标记的寿命与携带条目。

**寿命**使用 `x = floor(u * S)`，其中 `u` 在 `[0, 1)` 上均匀分布，以 `purpose = marker lifetime` + 稀有度 + 非空宝箱序号寻址。使用实际交付的稀有度，包括兜底结果。

记录选项前，`S` 统计通用、商店和送货员序列中，该稀有度当前可用、可进入宝箱的非角色专属品种数量，包含抽到的条目。排除先前宝箱选项与已消耗条目，包括未购买的商店展示品。

其他来源的消耗可缩短未来标记的寿命，但已有寿命固定不变。

**对齐**。后续抽取请求与资格一致且没有借用时，获取与跳过在标记到期前共享同一未来序列。

**原版偏差——NoSL 2**。宝箱标记寿命可能略微改变之后角色专属遗物奖励的概率（见[分析](#宝箱标记概率)）。

基线见[宝箱机制](#商店宝箱与遗物事件)。

### 药水

药水副本不携带持久选择状态；使用、丢弃和交易作用于选中的副本，保留依赖栏位的结果。

#### 生成

区分**通用奖励**、**商店**、**送货员**和**药水生成效果**。通用奖励合并战斗、事件和其他给予，不区分费用；生成效果包括炼制药水、混沌药水和娇嫩蕨草，也包含战斗外触发。

每个来源有覆盖完整合格池的普通/罕见/稀有品种序列，以及[标准权重稀有度序列](#药水-1)。通用品种均匀奖励使用按合格品种数量加权的独立稀有度序列，但共享品种序列。

**消耗**。直接加入物品栏的给予仅为成功获得的药水推进稀有度与品种状态，包括部分成功的批次。选项遵守[消耗时机](#机会消耗时机)，未领取也消耗。保留失败反馈。

**批次**。按瓶消耗并保留[来源去重规则](#药水-1)；重分组时 `A | BCD` 变为 `ABC | D`，受过滤条件约束。

**[重掷减少](#房间内重掷减少)——SL 4(↓)**。栏位已满时使用炼制药水不再能绕过不想要的药水。

**原版偏差——SL 4**。混沌药水/娇嫩蕨草生成现在可以重掷之后炼制药水的药水，反之亦然。

#### 掉落判定

每次掉落判定掷值由掉落判定序号派生。

**白兽雕像**冻结掉落判定序号与概率；强制奖励仍推进通用药水生成。

#### 稀有牌时机与交付

**范围**为三种本角色随机稀有度[选项组类别](#选项组类别)。

##### 运气与稀有度偏移量

**状态**。运气 `L` 从零开始，战斗偏移量 `o` 从 `-0.05` 开始。阈值为 `T = -ln(U)`，`U` 在 `(0, 1)` 上均匀分布。每个阈值由用途 + 阈值重置次数派生。

**逐卡位处理**。按顺序处理卡位，每个卡位为运气增加 `-ln(1 - p)`，`p` 是该卡位的稀有概率。

- 使用普通战斗或精英稀有度规则的卡位，采用 `max(0, base Rare chance + o)`，共享战斗偏移量。
- 使用不带战斗偏移量的基础稀有概率的卡位，既不读取也不修改 `o`。

**稀有牌交付**。在下述难度上限约束下，达到阈值的卡位成为稀有牌。运气归零，丢弃超出量，并为阈值取新值。

**战斗偏移量更新**

- 使用普通战斗或精英稀有度规则的非稀有卡位增加 `0.005`（无稀缺时为 `0.01`），上限 `0.40`。零概率卡位不增加运气，但仍增长偏移量。
- 上述任一类别交付稀有牌时，偏移量重置为 `-0.05`。
- Boss 奖励重置战斗偏移量，但保留运气和阈值。
- 幕间将偏移量重置为 `-0.05`，延续运气、阈值和序列状态。

**理由**。延后机制生效前，指数阈值保留输入的等待概率，即 `P(no Rare through n slots) = exp(-sum(-ln(1 - p_i))) = product(1 - p_i)`。

**竞赛影响——运气耦合**。三张牌的选项组在起始运气、阈值和偏移量相同时，若均未交付稀有牌，精英留下的运气多于普通战斗。该领先跨 Boss 奖励和幕间切换保留；后续增量相同时，精英分支不会更晚达到共享阈值。任一分支交付稀有牌后，此保证结束。

##### A7+：每组一张稀有牌及延后机制

每组选项最多一张稀有牌。若后续卡位达到下一个阈值，则按以下规则处理。

- 保留该待交付阈值，继续积累运气直到交付；最多只保留一张待交付稀有牌。
- 对适用的偏移量更新，被抑制卡位视为非稀有。

若忽略待交付结果，沿全部非稀有的进程至少有一个卡位稀有概率为正，则该组**可接收稀有牌**。

- **下一个可接收组**用待交付稀有牌替代首个模拟卡位的普通判定。清除待交付状态，应用[交付与偏移量规则](#运气与稀有度偏移量)，再正常处理剩余卡位。
- **不可接收组**保留待交付阈值，正常增长非稀有偏移量。

因此，偏移量重置后、未穿插精英时，按普通战斗稀有度规则生成的前两组三张牌不接收待交付稀有牌。交付遵循选项组生成顺序，包括额外选项组和重掷，并可跨幕等待。

**原版偏差——NoSL 2**。精英与固定概率选项组不再包含多张稀有牌。**频率**约为 [A7+ 校准](#稀有度校准)中每 500 局出现一次多稀有牌选项组。

**原版偏差——NoSL 2**。若原本会有三张或更多稀有牌，仅有一张额外稀有牌在之后提供。**频率**远低于上一项偏差（定性判断）。

##### A0–6：稀有牌交付

| A7+   | 38%          | 39%              |
| A0–6 | 40%          | 40.5%            |

这些取整概率近似[三幕校准](#稀有度校准)中展示罕见牌总数的期望。

**开局三元组**。整局前两个非稀有三元组，使用偏移量重置后连续两次普通战斗选项的[原版逐卡位概率](#卡牌奖励选项组-1)，条件为没有稀有牌。A0–6 下依次为 **35%, 36%, 37%**，再为 **37/99, 37/98, 37/97**。

这些三元组遵循跨来源共享消耗。

**理由**。这些条目近似第 1 幕连续两场普通战斗的开局，后续幕的开局由平均校准覆盖。

**原版偏差——NoSL 2**。共享概率改变不同来源与路线的罕见频率，包括移除精英的优势（起始偏移量接近零时，每组三张非稀有牌约少 0.14 张罕见牌）。

##### 补充卡牌

**脑蛭——分享知识**用事件 RNG 额外生成两张普通/罕见牌，排除组选项中已有品种。根据是否交付稀有牌使用[罕见概率表](#罕见概率)。

**满屋芝士——大快朵颐**使用一个普通三元组，其余五张普通牌由事件 RNG 生成。

##### A0–6：多张稀有牌

本角色随机稀有度选项组按角色共享一条额外稀有品种序列，独立于固定稀有三元组。含 `k >= 1` 张稀有牌时，从该序列抽取 `k - 1` 个条目，排除原始稀有牌和此前额外稀有牌。

每张额外稀有牌替换条目顺序中的第一张普通牌；若已无普通牌，则替换第一张罕见牌。应用于整个选项组，包括脑蛭的两张事件生成牌；两张稀有时，`R,U,U | C,C` 变为 `R,U,U | R,C`。被替换的伴随牌仍视为已消耗。

**替换状态**。品种与[升级掷值](#升级掷值)来自新稀有条目。保留被替换卡位的羽翼护符优先级或补充卡牌归属，以及选项组地址。

**接受的取舍**。先前稀有牌数量与伴随牌构成可能削弱同一三元组构建出的选项组之间的对齐。

**原版偏差——NoSL 2**。优先替换普通牌，使多稀有组选项更偏向保留罕见伴随牌。**频率**较低，约占 [A0–6 校准](#稀有度校准)中**原版精英选项组的 2%**。

##### 展示

本角色随机稀有度选项组中，先将原始稀有牌，再将按抽取顺序排列的额外稀有牌，依次交换到按卡位升序排列的模拟稀有位置。

脑蛭不含稀有牌的分享知识选项组，以及满屋芝士的大快朵颐选项组，在奖励调整效果后用事件 RNG 均匀打乱[显示顺序](#条目地址)。

##### 卷轴箱

抽取普通序列条目前，先用事件 RNG 结算故障机器人的两次独立 1% [三张爪击替换判定](#卡牌奖励选项组-1)。其他角色走无替换分支。

- **无替换**时消耗一个普通三元组，供给第一包的两张普通牌和第二包的第一张普通牌；剩余一张普通牌与两张罕见牌由事件 RNG 生成。
- **三张爪击例外**。若任一卡包被替换，其余常规卡包全部使用事件 RNG 生成。

#### 选项组流程

本角色随机稀有度选项组模拟稀有牌位置时，不包含吃不完的糖等调整效果添加的卡牌。

1. 按[稀有牌时机与交付](#稀有牌时机与交付)模拟三个卡位（脑蛭的分享知识模拟全部五个），记录交付稀有牌的位置。
2. 若交付了稀有牌，消耗下一个[含稀有三元组](#选项组序列)，否则消耗下一个非稀有三元组。这提供初始品种及普通/罕见稀有度。
3. 追加[补充卡牌](#补充卡牌)，再在适用时执行 [A0–6 额外稀有替换](#a06多张稀有牌)。

替换后应用奖励附魔，再将为模拟卡位生成的稀有牌[交换](#展示)到记录的位置。

#### 重掷

可达重掷按来源的[选项组类别](#选项组类别)及适用的[选项组流程](#选项组流程)生成，从该组序列中抽取未使用条目，包括[扩展池](#棱彩宝石与肮脏地毯)。

万花筒在涅奥处的选项组无法重掷。

#### 棱彩宝石与肮脏地毯

保留[原版改池限制](#卡牌奖励选项组-1)。换池保留运气状态与开局三元组进度。

**棱彩宝石**在地毯添加卡牌池前，若宝石扩展了合格池，则使用独立序列，否则复用已有序列。保留来源的三元组或逐条抽取方式，包括吃不完的糖的能力牌序列。

**取舍**。宝石牺牲与未扩展池的对齐，以避免扩池时重建序列。

**肮脏地毯**先生成不含地毯效果的来源基础选项组，持有宝石时保留宝石效果。消耗所有原条目，包括下文被替换的条目。固定普通或原本已全为无色的选项组不变。吃不完的糖遵循下文的独立规则。

在[额外稀有牌替换](#a06多张稀有牌)之后、奖励调整效果之前，按条目顺序处理卡牌。下文的原条目是额外稀有牌替换后的条目，而非被替换掉的伴随牌。

1. 统计该稀有度下合格的无色与非无色品种数，保留来源过滤，并排除本批次中此前保留或替换得到的品种。
2. 从 `purpose = Rug replacement` + 原卡牌条目地址派生均匀 `[0, 1)` 掷值。掷值小于 `无色品种数 / 总品种数` 时替换该牌。
3. 替换条目的地址为 `purpose = Rug colorless identity` + 原条目地址。用此地址在按卡牌 ID 排序的合格同稀有度无色品种中均匀选择。

遵循[额外稀有牌替换状态](#a06多张稀有牌)，同时保留该牌模拟得到的稀有牌位置。

除糖果外，地毯替换不使用共享的无色品种序列。

**理由**。卡牌奖励三元组按整组消耗。将地毯替换绑定到原条目可保留分组；若通过共享序列延续无色结果，较早的地毯替换次数就会影响后续选项组的替换。

**对齐边界**。条目的替换掷值和品种掷值保持不变，但合格候选变化（包括批次内排重）仍可改变是否替换及替换后的无色品种。

**吃不完的糖**在持有地毯时，按地毯处理后的选项组排重；用下一个 `[0, 1)` 掷值按上述品种数加权概率决定是否为无色。仅从选中的能力牌品种序列抽取并推进该序列。

使用专用的颜色选择掷值序列和无色能力牌品种序列，按稀有度划分，在有无宝石时共享。

### 未知房间解析

**寻址**。由 `purpose = room type` + 幕内房间类型序号派生均匀 `[0, 1)` 掷值。每次访问 `?` 推进一次，黄金罗盘或灯火钥匙强制的事件房除外。

**区间宽度**。执行排除后，按普通战斗 → 宝箱 → 商店顺序，根据已存概率分配宽度，每项不超过 100% 中剩余的份额。

**区间位置**。宝箱从 0 开始，商店在 1 结束。普通战斗以 `7/15` 为中心，仅为避免重叠而移动。剩余空间解析为事件。

**理由**。当宝箱/普通战斗/商店宽度按基础 `2:10:3` 比例填满区间时，普通战斗的中点是 `7/15`。

基线见[房间限制与概率更新](#未知房间解析-1)。

### 普通事件选择

**范围**为普通事件，不包括[先古之民](#先古之民馈赠)及[灯火钥匙强制事件](#灯火钥匙)。

**条件**。按等价资格谓词对事件 ID 分组，每种条件一个键，不包含幕可用性和[延后资格检查](#事件资格)。幕可用性决定参与的 ID，选择 ID 时再执行延后检查。

分组前，第 3 幕先古之民为坦克斯时排除战将神龛，为诺奴佩普时排除诺奴佩普的浴场。

#### 入幕与延续

**对齐**。接受罕见的更早失配，以提高两局都遇到的事件之间相对顺序的一致性。

对局开始时，按 `purpose = ID order` + 条件键独立打乱各条件的 ID。

入幕时，仅用本幕可用且未访问的 ID 重建各条件序列。保留剩余项顺序，并按新可用 ID 在开局时的顺序插入。

**排序随机优先级**。有 `n` 个剩余 ID 和 `m` 个新加入 ID 时，从独立均匀序列各取前 `n`、`m` 个掷值，以 `purpose = insertion` + 幕 + 条件键 + 剩余/新加入寻址。分别排序，按顺序分配给各自 ID 序列，再按优先级归并。交错顺序均匀分布。

**剩余计数**。将每个条件的计数重置为本幕可用、未访问的 ID 数量，即使当前条件不满足。

#### 幕内选择

每个条件分别追踪剩余选择尝试次数和事件 ID 序列位置，因而条件检查失败可以消耗一次尝试而不跳过事件。两者在每幕内跨选择延续。

**优先级持久性**

| 幕   | 条件优先级与掷值序列                       | 对齐目标                                   |
| ---- | ------------------------------------------ | ------------------------------------------ |
| 1    | 入幕时初始化，选择之间保留。               | 匹配事件相对顺序。                         |
| 2–3 | 每次选择使用新序列，按剩余计数刷新优先级。 | 先前访问导致池不同时，推迟本幕第一次失配。 |

1. 在上述时机，为每个剩余计数 `n_c > 0` 的条件初始化优先级 `-ln(U) / n_c`。从以 `purpose = condition selection` + 条件键寻址的序列中，连续抽取独立均匀 `U ∈ (0, 1)` 掷值。第 2–3 幕还包含幕内普通事件序号。
2. 将最低优先级条件的计数减一。若谓词通过且仍有未访问 ID，则尝试下一个未访问 ID 并推进 ID 位置，包括延后资格检查失败的情况。
3. 失败后，计数为零则停用该条件；否则为其优先级增加一个新的 `-ln(U) / n_c`。其他优先级不变，重复第 2 步。
4. 成功后提交访问和状态变化。第 1 幕按第 3 步更新胜出条件的优先级。

**回绕**。全部计数归零时，按本幕可用且未访问的 ID 补满计数，延续掷值序列并重新初始化优先级。ID 序列按既定顺序回绕，排除已访问 ID。

**原版偏差——NoSL 2**。回绕后刷新的条件优先级可能改变各事件出现概率。**频率**较低（定性判断）。

**兜底**。本幕没有合格未访问事件时，从原版原始打乱幕列表返回 `list[(n - 1) % list.Count]`，其中 `n` 是从 1 开始的幕内普通事件序号。本次抽取绕过资格和已访问排除。

**原版偏差——NoSL 2**。在给定先前访问与资格条件下，序号索引改变兜底时各事件出现概率。**频率**实际上几乎不可能发生（定性判断）。

**行为保留**。计数补满或 ID 回绕前，若资格判断无法读取隐藏顺序，则保留原版分布。延后资格检查通过时，相同起始随机状态 + 相同选中事件留下相同随机状态。跨对局和 SL 相关性改变。

基线见[事件选择与回绕](#事件与遭遇品种)、[条件谓词与延后资格检查](#事件资格)。

### 遗物交换商

**意图**。优先提高交出遗物的重叠，而非保留每件遗物与替换遗物的配对。

#### 替换遗物

按顺序生成奖励位置 1–3。每个位置以 `purpose = replacement rarity` + 事件 ID + 奖励位置掷[原版遗物稀有度](#遗物袋)，再按常规遗物资格，从该稀有度的[送货员配额](#配额分配)[尾部抽取](#遗物尾部抽取)。耗尽时使用[借用与兜底](#借用)。

提供选项时消耗全部三件替换遗物，包括借来的通用条目。

#### 交出遗物分配

1. 为每个可交易持有遗物/奖励位置配对，以 `purpose = outgoing assignment` + 事件 ID + 遗物 ID + 奖励位置赋予[配对优先级](#配对优先级分配)。
2. 每件遗物取三个配对优先级中的最小值，选择最小值最低的三件遗物。
3. 对这三件遗物和三个位置复用同一优先级，执行配对优先级分配。

**理由**。替换一件合格持有遗物时，至少保留两件交出遗物；在对称对待品种的规则中，交出遗物重叠的期望最大。

基线见[商店、宝箱与遗物事件](#商店宝箱与遗物事件)。

**默认选择**采用[固定优先级派生](#固定选择优先级)，键为 `purpose = Wing Charm` + [卡牌实例地址](#卡牌实例地址)，选择批次内优先级最低的合格卡牌。

**较大的非稀有选项组**。脑蛭的分享知识和满屋芝士的大快朵颐从三元组内选择；若其中无合格卡牌，则用事件 RNG 在合格补充卡牌中均匀选择。

**理由**。可互换的位置保留边际目标概率；[展示打乱](#展示)消除可见位置偏差。

**加权分组选择**。含稀有牌的分享知识和吃不完的糖中，若下述独立均匀 `[0,1)` 掷值小于 `eligible extras / all eligible cards`，则选择额外组，否则从三元组选择。

### 洗牌

**意图**。第 1–2 幕按来源对齐卡牌。到第 3 幕，牌组差异可能过大，基于来源的匹配不再实用，因此改按实用性排名对齐。

**范围**为开场与后续洗牌，使用卡牌当前[逻辑关联](#路由)。结果不依赖输入牌堆顺序。

在同一尺度上分配独立均匀优先级，按优先级排序后，应用起手与洗牌调整效果。

每次洗牌以 `purpose = shuffle` + [战斗地址](#战斗地址) + 战斗内洗牌序号寻址。全部触发来源共享此序号，每次洗牌推进一次，包括空牌堆和单牌洗牌。

洗牌键使用[战斗卡牌键分配](#战斗卡牌键分配)，每次洗牌重新分配序列位置。每张牌的优先级由洗牌地址 + [洗牌键](#卡牌标识)派生。

开场洗牌为固有牌分配独立优先级序列，按[处理顺序](#卡牌处理顺序)排列，最无用的在前。其余卡牌采用共享分配。

#### 原版偏差

**[重掷减少](#房间内重掷减少)——SL 4(↓)**。牌堆插入，以及对品种与升级等级相同的弃牌副本重排，不再重掷洗牌，包括狂乱逃离的哪个费用副本先抽到（见[基线](#战斗初始化与洗牌)）。抽牌顺序备选减少可能削弱抽牌效果。

**消耗**。在 0–3 上均匀掷值，每次合格掷值消耗一个条目。混乱的 X 牌，以及抽到后已离开手牌的蛇行牌，不消耗。

**混乱 + 蛇行**。同次抽牌两者均适用时，蛇行在通常时机重新应用该次混乱值，且仅限卡牌仍在手中。不消耗蛇行条目。重新应用仍会覆盖王者之踢的抽牌减费。

**异蛇之油分配**。异蛇之油抽牌结束后，各类别内的合格卡牌按最近一次成功进入手牌的时间由早到晚排序。

- 抽取、取回和生成都获得入手位置。保留牌维持原位置；离手后再次入手刷新位置。
- 无序入手批次共享一个入手序号，批内按入手时冻结的[处理顺序](#卡牌处理顺序)升序排列。
- 顺序抽牌和明确有序的取回（包括万物一心）保留来源顺序。

异蛇之油入手分配应用[战斗卡牌路由](#战斗卡牌路由)。

**[重掷减少](#房间内重掷减少)**来自来源/类别分区、跳过 X 和混乱/蛇行重叠时复用值。

**[重掷减少](#房间内重掷减少)**来自异蛇之油对无序入手批次的处理顺序。

基线见[随机能量费用](#随机能量费用-1)。

### 偏差评级

评估同一种子的首次游玩。

不影响玩法的一致性修复不评级。

**不可察觉**指综合频率与效果幅度后，跨对局仍无法感知；对胜率的影响可作为支持证据。以 500 局为粗略基准，参照 [A7+ 每组一张稀有牌上限](#a7每组一张稀有牌及延后机制)。

**策略中立**指知情玩家不会据此有意义地改变策略。

| 等级         | 影响                           |
| ------------ | ------------------------------ |
| **1**  | 仅展示。                       |
| **2**  | 不可察觉且策略中立的玩法变化。 |
| **3A** | 可察觉且策略中立。             |
| **3B** | 不可察觉且非策略中立。         |
| **4**  | 可察觉且非策略中立。           |

**游玩模式**

- **NoSL**不存读档，评估房间内和上层策略。
- **SL**在提交到下一存档状态前，从当前存档探索全部可用操作序列。评估可达的最佳房间结果、上层决策，以及影响后续房间的房间内选择，例如携带哪些药水。

各模式独立评级。两者不同时写 `NoSL x, SL y`，相同时写 `NoSL x`，仅影响 SL 时写 `SL x`。

**策略变化记法**。在 3B/4 级中，**↓** 表示有意义的决策简化，**↑** 表示复杂化；无直接箭头表示取舍改变。SL 的括号箭头在任意等级描述房间内探索，例如 `4(↓)` 表示策略改变而探索简化。

罕见偏差包含**频率**字段。

### 宝箱标记概率

未见顺序均匀且资格固定时，在借用或供给耗尽前，用[有限寿命标记](#有限寿命宝箱标记)获取一次宝箱遗物，与原版在该稀有度通用奖励中的角色专属概率一致。均匀寿命对角色专属位置的影响类似于删除一个随机的宝箱合格位置。先前抽取可能破坏均匀性。

以下示例含一件角色专属遗物，其余均非角色专属，且全部可进商店。模组随机分配一件给商店库存，其余均匀排序为通用库存。原版使用[独立遗物袋](#遗物袋)。每行给出下一份通用奖励为角色专属的概率。

| 池大小 | 顺序                                 | 原版  | 模组  |
| ------ | ------------------------------------ | ----- | ----- |
| 4      | 商店展示 → 获取宝箱遗物             | 37.5% | 37.5% |
| 6      | 跳过宝箱遗物 → 商店展示 → 获取宝箱遗物 | 20.8% | 21.1% |

第二例增加 **0.3 个百分点**，因为商店消耗改变新寿命，却保留已有寿命。若改为将已展示商店遗物计入 `S`，第一例的模组概率会降到 **33.3%**。

### 未采用的方案

#### 宝箱配额

独立宝箱配额会增加奖励来源间的不公平，因此[宝箱](#遗物推进)使用通用遗物供给。

#### 战斗金币备选方案

与[按类别的金币掷值](#战斗金币)相比，共享掷值有以下取舍。

- **独立补偿**保持期望不变，但使 A3+ 普通金币不再均匀（**原版偏差——NoSL 2**）。普通/精英重排可使圆顶礼帽总量相差 1。
- **按区间相对位置掷值**保留原版分布，但重排可使 A3+ 基础金币相差 1。

#### 事件选择备选方案

[幕内选择](#幕内选择)若每幕都保留优先级，在剩余池相同时相对顺序更好，但剩余池不同时可能更早失配。每幕都刷新会改善同序号匹配，却增加第 1 幕顺序颠倒。

[跨幕插入](#入幕与延续)中，用共享输出位置优先级预留新加入位置，或用按剩余数量加权的共享掷值选择剩余/新加入 ID，虽然有时推迟第一次失配，但在[模拟](../research/README.md#event-selection)中保留的相对事件顺序更少。

#### 遗物交换商备选方案

在移除/替换一件合格遗物，且两局三件不同替换遗物按位置匹配的条件下，[分析](../research/relic-trader/results.json)比较了[采用的分配](#交出遗物分配)与两种备选。

- **独立候选优先级**具有相同的交出遗物重叠期望，但平均匹配的交出/替换配对更少。
- **在全部合格遗物上直接配对**平均匹配配对更多，但一次库存替换可能改变两件交出遗物。

#### 老鼠采样备选方案

[非召唤选择](#老鼠采样)的备选方案如下。

- **百分位采样**在资格变化时移动保留行动的掷值区间。
- **每对合格行动独立序列**失去跨行动对的对齐，且未解决选择次数差异。
- **[过滤抽取](#过滤抽取)**在资格收敛后仍保留过滤历史差异。

### 房间、事件与战斗

#### 未知房间解析

**选择**按普通战斗 → 宝箱 → 商店顺序采样累计概率，剩余部分为事件。基础概率为 10% / 2% / 3%；禁用精英。被排除类型不占区间。

**溢出**时仅选择顺序中前 100% 可达，已存概率不设上限。因此 70% / 14% / 21% 得到实际 70% / 14% / 16%，事件为 0%。

**概率更新**。选中的非事件类型重置为基础概率，其他允许的非事件类型各增加自身基础量。被排除类型的已存概率冻结。

**随机状态**。每次 `?` 解析推进 `UnknownMapPoint` 一次，包括强制事件，后者冻结非事件概率。幕间概率重置，RNG 状态延续。

#### 事件与遭遇品种

**预先生成**。`UpFront` 构建各幕事件与遭遇列表，并选择先古之民。事件列表均匀打乱本幕专属与共享品种。后续幕在选择前获得互不重叠的共享先古之民子集。

**事件**扫描打乱列表，寻找下一个合格且未在整局访问集中的品种，跳过失败条目。之后才执行强制事件替换。

**回绕**保留列表顺序与访问记录。跳过条目可能在后续扫描合格；完整扫描仍失败时返回游标处事件，即使重复或不合格。

**普通遭遇**取下一个普通遭遇，不论地图标记是 `?` 还是普通战斗。

**容量**。过滤前各幕事件列表有 28–32 条，而每幕普通楼层为 13–15 层。

**事件 RNG**在单人中以对局种子 + 确定性的事件 ID 哈希设置种子（`EventModel.BeginEvent`）。

**跳过与概率**。隐藏顺序均匀、其他资格固定且未回绕时，跳过隐藏的不合格条目保留它们之后的概率。有两个 K 事件和三个其他事件时，在 K 不合格期间遇到零、一或两个非 K 事件，K 恢复合格后下一次选中 K 的概率仍为 `2/5`。K 合格期间的遭遇则产生通常的无放回影响。

| 人形洞穴之地 | 一张可附完美契合的牌 |
| 滑脚木桥     | 一张可移除卡牌       |

**强制事件**。灯火钥匙的战史学家 付袭是唯一会强制替换普通事件抽取的事件；`IsAllowed` 始终为 false。

#### 无尽传送带菜品

进入时和每次购买效果后生成菜品，即使下一次已买不起。每第五次展示固定为海洋混混沙拉；其他展示用一次加权事件 RNG 掷值，排除上道菜。

| 菜品                     | 权重 | 附加条件       |
| ------------------------ | ---: | -------------- |
| 鱼子酱                   |    6 | 无。           |
| 香辣薄脆/水母肝/炸鳗鱼 | 各 3 | 无。           |
| 可疑调味料               |    3 | 有空药水栏位。 |
| 蚌肉卷                   |    6 | 生命值未满。   |
| 金色异鱼                 |    1 | 首次展示之后。 |

水母肝的变化和香辣薄脆的随机升级也使用事件 RNG。

#### 战斗初始化与洗牌

**遭遇初始化**。RNG 以对局种子 + 总楼层 + 遭遇 ID 设置种子，采样可变组成和初始状态。

**洗牌 RNG**。开场洗牌、重洗和随机插入牌堆跨战斗共享 `Shuffle`。

**洗牌**。开场洗牌从按牌组顺序复制的卡牌开始。重洗先将弃牌/抽牌合并后按品种和升级等级排序（`StableShuffle`）。每次洗牌（包括空/单项列表）用父 RNG 的一次 `NextUnsignedLong` 调用为子 RNG 设置种子，再执行 Fisher–Yates 并应用调整效果。候选数量变化不改变父 RNG 消耗。即使附魔、持久进度或战斗状态不同，排序也可能将副本视为并列，因此输入顺序会影响结果。

**叽 唱诵**。洗牌补充不足的抽牌堆后，将洗牌前剩余卡牌按原顺序恢复到堆顶。

**弃牌顺序**影响手牌空间有限时的万物一心，以及好勇斗狠和能量汲取使用的洗牌。狂乱逃离每打出一次，本场战斗费用 +1，可使并列副本费用不同，从而改变哪个费用先抽到。

**随机插入**。`n` 张牌的牌堆中，`CardPileCmd.Add` 用 `Shuffle.NextInt(n + 1)` 均匀选择空隙。生命周期保护检查在掷值前执行。

#### 敌人生命值

**生成**。`Niche` 在初始生命值含端点区间中均匀采样，排除敌人列表已有的 `MaxHp` 值。候选为空则恢复完整区间。每次创建推进 RNG 一次，包括固定区间和单候选（`Creature.SetUniqueMonsterHpValue`）。

**顺序**。敌人通常依次创建并加入，包括召唤。死亡触发的生成在濒死敌人移除前掷值。地精佣兵则先创建胖地精，再创建并加入卑鄙地精，最后加入胖地精，因此二者都不排除对方生命值。

**特殊情况**。结实的卵孵化用 `Niche` 在完整幼体区间重掷。残杀千足虫各体节将生命值调整为不同偶数。重拳出击的初始削减使用遭遇 RNG。

**固定生命召唤物**为利齿之眼（6）、寄生惧魔（21）及气态炸弹（按进阶为 7/8）。

#### 敌人 AI

**选择**。整局 `MonsterAi` 提供行动选择与组装师机器人品种。随机分支按声明顺序采样累计有效权重，计入重复限制、冷却和条件。单候选/全零分支推进 RNG 一次；确定性转移不改变 RNG。遭遇分配的开局使用初始化 RNG。

**全零兜底**。全零分支总是选择列表首个行动。飞蝇菌子可达到“猛砸 → 易伤孢子 → 脆弱孢子 → 猛砸”，使全部有效权重为零，然后选择易伤孢子。

**历史与打断**。`MonsterMoveStateMachine` 保留状态日志供权重检查。击晕后回到存储行动；偷窃草蜢的振翅耗尽使用确定性后续。残杀千足虫循环“扭动 → 紧缠 → 胀大”；“死亡 → 接续”之后，用共享 AI RNG 在这些攻击中等概率选择。

**重复敌人类型**。墨宝与老鼠见下文，其他情况如下。

| 敌人                           | 行动模式                                                                               |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| 蛇行扼杀者身旁的小型树叶史莱姆 | 随机开局，之后通过随机分支强制交替。                                                   |
| 外骨骼虫                       | 激怒后等概率选择忙乱/啃食；忙乱强制接“啃食 → 激怒”。普通遭遇的第四只副本随机开局。 |
| 咬人卷轴                       | 首次咀嚼后，等概率选择大啃/咀嚼；第二次咀嚼强制接“大啃 → 更多牙齿 → 咀嚼”。       |

**墨宝死亡时机**。两侧以刺击开局，在刺击与锐利凝视/旋风的 50/50 选择间交替；中间以旋风开局。在中间第一次随机选择前将其击杀。若在外侧 A 的一次随机选择之前或之后击杀 A，B 的第二次及后续选择会相差一次 RNG 推进，即使合格行动相同。

**老鼠资格**。召唤依赖计时器、共享上限、空间和队友意图。尖锐鸣叫冷却中且两种攻击都合格时，启用召唤会将攻击/攻击概率 `1/2, 1/2` 变成攻击/攻击/召唤概率 `1/11, 1/11, 9/11`，同一掷值因此可能选中不同攻击。“尖锐鸣叫 → 抓挠”后禁用召唤会强制疾病啃咬，但仍推进 RNG。

**老鼠选择顺序**。按 `first` 到 `fifth` 位置，初始老鼠占最后三个。较早的召唤选择会阻止后续老鼠召唤。其他条件下合格概率同为 `p` 且无已有召唤意图时，依次概率为 `p`、`(1-p)p` 等。已有队友意图也可能阻止较早选择者。

**老鼠历史备选**。初始老鼠分别以抓挠、疾病啃咬和尖锐鸣叫开局。召唤受计时器限制时，在首次随机选择前击杀尖锐鸣叫开局者和任一攻击者。剩余者在抓挠后提供啃咬/尖锐鸣叫，在啃咬后提供抓挠/尖锐鸣叫。原版 SL 能找到尖锐鸣叫的概率为 50%；共享行动排名或标记过滤的独立均匀序列为 `2/3`，同时各存活者仍保持 50/50 概率。对三对等权开局历史取平均，百分位采样与共享优先级的一致率均为 `1/3`。

**跨类型推进**。在“树叶史莱姆（小）→ 树枝史莱姆（中）→ 树枝史莱姆（小）”中，击杀任一小史莱姆可能移动中型树枝史莱姆的下次掷值。小型树叶史莱姆的强制交替推进 AI RNG，小型树枝史莱姆的固定攻击不推进。

**存活者选择备选**。飞蝇菌子开局为“猛砸 → 脆弱孢子”，树枝史莱姆（中）为“黏糊射击 → 攻击”。假设可在下次意图选择前击杀任一只，唯一存活者使用相同的下一个 AI 掷值。

| 掷值区间 | 飞蝇菌子存活 | 树枝史莱姆（中）存活 |
| -------- | ------------ | -------------------- |
| 下半区   | 易伤孢子     | 攻击                 |
| 上半区   | 猛砸         | 黏糊射击             |

恰有一种击杀会得到下一次零伤害意图；看到意图前概率 50%，SL 探索可保证获得。

**同类型存活者备选**。保留一只已执行“抓挠 → 疾病啃咬 → 召唤 → 抓挠”的初始老鼠，以及一只以抓挠开局的召唤副本，移除其他老鼠。两者随机选择次数分别为三和一。在抓挠执行前击杀任一只，两种存活者均以 50/50 提供疾病啃咬（A7+ 为 7 伤害）/尖锐鸣叫（脆弱，零伤害）；原老鼠已用完召唤，副本受计时器限制。原版共享的下一个掷值让两种击杀得到相同结果。

**组装师**。组装先选择守护机器人/噪音机器人，再选择电击机器人/戳刺机器人；组装打击仅选择电击机器人/戳刺机器人。每次抽取跨两池排除上一个机器人，因此防御机器人允许此前的攻击机器人再次出现。容量满时强制瓦解；机器人使用固定行动。击杀/击晕时机改变选择时机，但保留机器人顺序和品种。

#### 随机敌方目标

直接随机效果和自动敌方目标选择共享整局 `CombatTargets`，在合格敌人中均匀采样。单候选推进 RNG 一次，空集不推进。自动打出和闪电保留已提供的目标；本身随机命中的效果每击掷值，允许重复。

**铭记死亡**选择可命中敌人中生命最低者，同值按枚举顺序打破平局。

### 遗物、商店与宝箱

#### 遗物袋

**两个重叠的袋**。玩家袋包含 **122 件常规遗物**，普通 26、罕见 32、稀有 38、商店 26（115 件非角色专属 + 7 件角色专属）。宝箱袋（`SharedRelicGrabBag`）仅含非角色专属遗物。各袋分别打乱每种稀有度列表。

**抽取**。稀有度为 50% 普通 / 33% 罕见 / 17% 稀有，普通奖励用玩家 `Rewards`，事件奖励用事件 RNG，商店用 `Shops`，宝箱用 `TreasureRoomRelics`。固定稀有度请求跳过掷值，Catfood 亦然。普通奖励和旺购百货从玩家袋头部抽取；商店从尾部抽两件随机稀有度遗物和一件商店遗物；宝箱从宝箱袋头部抽取。

**消耗**。普通奖励/商店生成时从两个袋移除品种，即使拒绝或不买。宝箱生成仅从宝箱袋移除。获取不可叠加遗物会从两袋移除，保留剩余项顺序；跳过宝箱遗物不改变玩家袋。

单稀有度示例，左侧为头部，`K` 为角色专属。获取与跳过是生成后的两个备选分支。

| 阶段     | 宝箱袋      | 玩家袋        |
| -------- | ----------- | ------------- |
| 宝箱之前 | `B D A C` | `A K C B D` |
| 生成 B   | `D A C`   | `A K C B D` |
| 获取 B   | `D A C`   | `A K C D`   |
| 跳过 B   | `D A C`   | `A K C B D` |

**资格**。`IsAllowed` 失败的遗物从被查询袋的所有稀有度中清除；来源过滤保留跳过条目。商店与旺购百货要求 `IsAllowedInShops`，排除紫水晶茄子（普通）、圆顶礼帽与招财异鱼（罕见）、古钱币与送货员（稀有）。旺购百货是唯一带品种过滤的非商店常规袋调用方。遗物交换商对交出遗物过滤可交易性，替换遗物使用常规资格。

**过滤抽取**从请求端移除首个合格条目。某稀有度均匀打乱，含两个商店可用和一个商店不可用品种时，概率如下。

| 首次抽取 | 下次无约束头部抽取为商店不可用的概率 |
| -------- | ------------------------------------ |
| 无       | `1/3`                              |
| 过滤头部 | `2/3`                              |
| 过滤尾部 | `1/3`                              |

头部偏差可能影响之后多个位置，取决于袋的组成。

**宝箱概率**。未见玩家袋顺序均匀时，获取独立选出的非角色专属品种，使每个剩余位置为角色专属的概率从 `C/N` 升为 `C/(N-1)`，例如 `5/100` → `5/99`。`N` 是该稀有度剩余品种数，`C` 是其中角色专属数。这些边际概率假设没有进一步观察或限制；此前过滤抽取可能破坏均匀性。

**楼层资格**。以下 17 件遗物在标准单人中要求 `TotalFloor < 41`，多人中要求 `< 38`（`RelicLists` 和 `RelicModel.IsAllowed`）：紫水晶茄子、五轮书、圆顶礼帽、火龙果、冻结之蛋、壶铃、佛珠手链、吃不完的糖、招财异鱼、餐券、熔火之蛋、古钱币、活动星图、铲子、毒素之蛋、白兽雕像、白星。截止条件使用总楼层，而非是否访问过宝箱。

**耗尽**。单人袋耗尽后不补充；从请求稀有度沿商店 → 普通 → 罕见 → 稀有查找，最后用头环。多人宝箱袋先补充请求的空稀有度，并可使用多人兜底池。Catfood 继承此行为。

#### 商店、宝箱与遗物事件

**可交易遗物**。兰伟德与遗物交换商共用 `RelicModel.IsTradable`，排除初始/事件/先古、拾取即生效、已用尽、已融化及生成宠物的遗物。

| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 宝箱                   | 入房时生成遗物，打开时用 `Rewards` 生成基础金币。必须打开宝箱才能离开，但可以跳过遗物。池与消耗规则见[遗物袋](#遗物袋)。                                                                                                                                  |
| 涅奥——白银熔炉       | 第一个宝箱房为空，没有金币和遗物。                                                                                                                                                                                       |
| 旺购百货               | 第 2 幕，所有玩家金币 ≥100。展示稀有遗物售价 200，提供时即从库存移除，即使买不起或拒绝，削弱之后遗物结果的一致性。隐藏普通遗物售价 100，购买时生成。二者都要求 `IsAllowedInShops`。离开时若有已升级牌，随机降级一张。 |

#### 商店与送货员 RNG

**共享 RNG**。初始库存与送货员补货用玩家 `Shops` 决定稀有度、卡牌/药水品种和价格。任意补货都可跨类别改变之后库存。遗物品种遵循选中稀有度内的袋顺序。

**卡牌**。初始无色位请求罕见/稀有；角色牌向下一个可用稀有度兜底。生成排除展示中的牌，包括补货时刚买下的牌。被抑制的随机升级仍消耗一次判定。

### 卡牌

**卡牌池**中不存在普通能力牌。

#### 卡牌状态与选择

**战斗卡牌选择**通常使用 `CombatCardSelection`，包括随机自动打出选择。`NextItem` 对空输入不消耗，单候选消耗一次。`TakeRandom` 先洗牌再取，即使请求零张；父 RNG 消耗与 `StableShuffle` 排序见[洗牌机制](#战斗初始化与洗牌)。

**战斗外玩家选择批次**。牌组选择器和奖励网格先收集无序选择，再应用效果。枚举可能影响获取顺序，例如海玻璃。

**牌组选择操作**包括升级（锻造）、附魔（扭曲锤子）、移除（空鸟笼）、变化（星盘、利爪、木雕）、多牌合一（熔合者）、暂存待归还（佩尔之牙）和复制（多利之镜）。旺购百货与镜中倒影  影倒中镜随机降级；奖励选择获取新实例。已检查的 Catfood 补丁未添加操作类别。

**持久卡牌状态**。`SerializableCard.Equals` 比较品种、升级等级和附魔，不比较卡牌特有存档属性。遗传算法维护 `CurrentBlock = 1 + IncreasedBlock`；巨镰维护 `CurrentDamage = 13 + IncreasedDamage`。炫技保存 `IncreasedAim`，通过关联牌组卡写入增长；其能力保留打出副本，直到敌人死亡或回合结束。打造时间给予一张配置好的疯狂科学；后续复制品继承类型/附加效果配置。多利之镜排除任务牌，包括藏宝图。

**疯狂科学——精进**。战斗后，用 `CombatCardSelection` 永久升级不同的合格牌组卡，每层能力一张。

**镜中倒影  影倒中镜**用事件 RNG 随机降级最多两张不同已升级牌，再升级最多四张不同可升级牌，包括刚降级的牌。

**偷窃草蜢**在支持的对局中最多出现一次且只偷一次。用 `CombatCardSelection` 从关联牌组卡（`DeckVersion`）的非任务抽牌/弃牌副本中均匀选择，使用首个非空的稀有度/附魔偏好层；全部层为空时使用所有候选（`ThieveryMove`）。偷窃移除牌组卡；草蜢死亡将同一对象作为可跳过奖励提供（`SwipePower`、`SpecialCardReward`）。逃跑或跳过则保持移除。

**佩尔之牙**储存玩家选中的五张可移除、可升级牌。每场战斗后，用 `Rewards` RNG 随机归还一张储存卡并升级。

**华美手镯**用 `NonCombatGeneration` RNG，为最多四张随机合格牌组卡附迅速 2。

**能量电池**先采样零费非固有牌，再采样零费固有牌，各层分别洗牌。

**傻瓜/愚者**每次选择前重新评估手牌候选。傻瓜从不含“不能被打出”的最低能量费用层选择（X 最后）；愚者排除“不能被打出”的牌。

混沌、化废为宝和魔术师使用整局 `CombatOrbGeneration`，从闪电、冰霜、黑暗、等离子和玻璃中均匀采样。先掷值再生成，因此失败尝试仍消耗 RNG。当前栏位为零时，无基础栏位的角色获得一个栏位；故障机器人无法生成（`OrbModel.GetRandomOrb`、`OrbCmd.Channel`）。

#### 滑脚木桥选择

选项用事件 RNG 在合格卡牌副本间均匀选择，重复副本分别计数。永恒阻止移除。

- **首个选项**为可移除的非基础牌。
- **重掷**记录被拒副本。从可移除牌中排除已拒副本和上次选项的整个品种。允许基础牌。
- **候选为空（包括首次）**时退回全部可移除副本。保留已拒集合，下次重掷重新应用过滤。兜底可能在每份副本都被提供前重复某副本或品种。

#### 永久变化与直接添加

**随机变化结果**使用原卡池；任务牌及事件/先古/衍生稀有度使用无色池。衍生是小刀、灵魂等生成卡牌的稀有度。常规结果为普通/罕见/稀有；诅咒共享一个诅咒池。保留解锁/玩家限制，排除原品种。战斗变化还要求 `CanBeGeneratedInCombat`，且可使用状态牌池。

`CardFactory` 过滤时保留池顺序，均匀选择合格索引，每张消耗一次掷值。批内允许重复。永久变化调用方提供事件 RNG 或玩家 `Transformations`。

**批次顺序**。星盘、变形灵林谷和审判使用返回的选择顺序；潘多拉魔盒使用牌组顺序；树叶药膏先打击后防御。`CardCmd.Transform` 先结算结果，再按记录的牌堆位置排序。不同合格列表可使结果多重集依赖顺序，即使只有一种原卡能替换成另一种。相同的有序列表保留多重集，例如潘多拉魔盒等本角色基础打击/防御批次。

**继承属性**。利爪将原卡升级状态和兼容附魔复制给撕咬（`Claws.CreateMaulFromOriginal`）。

**直接添加**使用 `Rewards`、`NonCombatGeneration` 或事件 RNG。被寄生的自动机械和炸鳗鱼在品种前按[基础稀有度概率](#卡牌奖励选项组-1)掷值，与战斗偏移量独立。不可用稀有度按普通 → 罕见 → 稀有 → 普通推进。奥术卷轴和随机诅咒给予从合格品种中均匀选择。

### 药水

**房间寻址**使用累计普通战斗/精英/Boss/商店/事件/先古之民计数。先古之民同时增加 `eventEntered` 与 `ancientVisited`；菜单保留原版种子。事件卡牌奖励覆盖使用 `eventEntered`，先古之民改用 `ancientVisited`。入房以对局种子和房间类型计数重新设置玩家 `Rewards` 种子，不同类型用不同乘数，并以普通战斗兜底。宝箱金币使用该兜底，没有宝箱序号。金币区间、取整和白银熔炉的抑制保留原版。

**先古之民选项**。`MassAuditionMode` 从涅奥正面池移除羽翼之靴，从诺奴佩普池移除皮草大衣。

**商店**使用商店序号和独立卡牌稀有度状态。卡牌品种/价格与遗物袋保留原版生成器；遗物稀有度和药水批次按下述方式改变。

**遗物稀有度**消耗预计算的 400 次掷值列表，第 401 次会失败（代码发现，尚未实战复现）。

**药水**。掉落判定种子依赖玩家种子和从 0 开始的累计索引，保留原版动态概率。强制掉落推进索引。工厂用另一共享调用索引为批次设置种子。

**战斗卡牌奖励**。品种/升级 RNG 使用房间类型、计数和选项位置。稀有度掷值先于品种抽取，稀有牌也一样；跨稀有度共享同一品种序列。稀有度偏移量重置与去重可改变后续品种。初始和重掷选项共享同一对象，因此赋值重掷 RNG 会覆盖初始选项 RNG；玩法影响尚未复现。

**卡牌稀有度**。普通战斗与精英有独立偏移量，使用原版基础概率、增长和稀有重置。商店固定偏移量，稀有概率为 0%（A0–6 为 4%）。进入先古之民（包括涅奥）将全部偏移量重置为 `-0.05`。Boss 奖励既不使用自身存储偏移量，也不重置普通/精英偏移量。战斗重掷更新对应房间类型偏移量，可能移动后续选项。

**直接/事件生成**。卡牌工厂种子结合房间/事件计数与房间内选项调用索引。和相等时碰撞，例如计数 1/调用 1 与计数 2/调用 0；有害玩法影响尚未验证。变化保留调用方提供的 RNG。二者均不按池共享品种序列。

**战斗初始化**。事件/遭遇品种保留原版选择。遭遇 ID + 房间类型序号控制可变组成/初始化；常规生命值不变。可见初始化失配尚未复现。灯火钥匙的强制事件正常计数。

**洗牌**在战斗开始时重新设置洗牌 RNG 种子，之后洗牌延续它。
