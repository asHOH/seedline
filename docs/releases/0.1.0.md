# Seedline 0.1.0

First release of Seedline, a Slay the Spire 2 mod that gives same-seed runs similar rewards, choices and combat challenges across different routes and decisions.

For example, reshuffling an extra time in one fight no longer changes the next fight's opening hand by itself. Your route, deck and decisions still affect the run. Some probabilities and save/load reroll options change to keep experiences similar.

## Requirements

- Windows and **StS2 v0.113.1 (`public-beta`), build d09d48e5**.
- Standard or Dread single-player, without custom modifiers.
- RitsuLib is optional. If used, keep its complete package, including `compat/0.113.0`.

## Install

1. Download **Seedline-0.1.0.zip**, not the source-code archive. The accompanying `.sha256` file provides its SHA-256 checksum.
2. Close the game. Extract the `Seedline` folder into the game's `mods` folder, creating `mods` if needed. The result should include `mods/Seedline/Seedline.dll` and `mods/Seedline/Seedline.json`.
3. Enable **Seedline / 不歪种神器** in the game's mod loader and start a new run.

New runs use fully unlocked content without changing profile unlocks or Ascension limits.

## Compatibility and limits

- Save/load exploration differs more from vanilla. Some actions no longer reroll outcomes.
- Modded characters retain reward and enemy alignment, but many card and player-side combat effects keep their original behavior.
- Keep the game build and mod setup fixed during a run. Disabling Seedline can discard its saved state. Start a new run after incompatible updates.
- Steam Cloud uses the game's existing support. Simulated cloud tests are included, but live synchronization remains unverified. Keep save backups outside the game's save directory.

See the [compatibility guide](https://github.com/asHOH/StS2/blob/v0.1.0/docs/compatibility.md) for tested and incompatible mods, and the [gameplay design](https://github.com/asHOH/StS2/blob/v0.1.0/design/DESIGN.md) for rules and tradeoffs.

## Validation

Release validation covers formatting, Release builds, foundation tests, isolated headless game integration checks, and RitsuLib 0.6.14 with both mod initialization orders. It does not replace live gameplay or Steam Cloud testing.
